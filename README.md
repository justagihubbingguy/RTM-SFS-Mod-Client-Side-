# RTM-SFS-Mod-Client-Side

⚠️ **Note: This mod is currently under active development and is not yet done**

A client-side multiplayer mod for **Spaceflight Simulator (SFS)**.

## Planned Features
* **Real-Time Multiplayer (RTM):** Connect and see other players in SFS.
* **Client-Side Optimization:** Smooth performance without altering the current installation.
